# 泛式 · 格式转换工作台（在线版）

纯静态站点，打开即可用，不上传任何文件。

## 能力

| 模块 | 说明 |
|---|---|
| 图片转换 | PNG / JPG / WebP / AVIF / BMP / ICO 互转，批量、缩放、质量、透明填充 |
| 音频转换 | MP3 / OGG(Opus) / WAV / AIFF 互转，NCM 解密，标签与封面 |
| 文档转换 | 图片合成 PDF、文本排 PDF、PDF 反向导出、**Word(.docx) → PDF** |
| 文库提取 | 在线版用书签或粘贴正文（纯静态站点受同源策略限制，不能直接抓跨站页面） |

## 部署

见仓库根目录的 `DEPLOY.md`，三种方式任选：网页拖拽上传 / git push / GitHub Actions。

## 目录

```
index.html               主界面（五个视图，hash 路由）
manifest.webmanifest     PWA 清单（可安装到桌面/主屏）
sw.js                    离线缓存
assets/                  样式、脚本、图标
tools/
  guide.html             使用向导（三条路图文）
  wenku_bookmarklet.html 书签生成页（文库提取的可用路径）
```

## 关于文库提取

浏览器同源策略不允许网页读取别的站点，所以纯静态部署**无法**直接抓取文库页面。
两条可用路径：装书签（在目标页面执行，不受限制），或把正文粘进来再导出 PDF / TXT。
需要在本机直接抓取时，用桌面版（带本地转发层）。
