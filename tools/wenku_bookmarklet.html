文库提取书签

在你自己已登录的页面里取内容：有文字层导文字，纯图片文档导页面图打包 zip。

泛式 · 提取本文
  1. 把橙色按钮拖到浏览器书签栏（或点「复制书签代码」，新建书签粘进网址栏）。
  2. 用同一个浏览器打开文库文档页，等正文渲染出来。
  3. 点书签：文字型文档导出 .txt；图片型文档（扫描件 / 整页图）导出 .zip，里面是逐页 PNG/JPG。
为什么它能拿到 API 拿不到的东西
  • 百度的 retype/zoom 图片接口对匿名请求返回 0 字节，retype/json 直接报防盗链 —— 图片页只能靠浏览器渲染；
  • 这个书签在页面上下文执行，拿的是已渲染的 canvas / img，不受接口鉴权限制；
  • 不动用你的账号做任何请求，文件由浏览器本地生成。
如果还是空
  • 先把页面整篇滚动到底——懒加载的正文与图片要滚过才会进 DOM；
  • PPT 播放器要逐页点过去，虚拟列表才会生成对应节点；
  • 仍不行按 F12 → Console 看 [泛式] 开头的日志。
