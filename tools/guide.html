三条路，按你手上有什么选一条就行

1最快的一条：书签（推荐）

①
拖一次书签

打开下面的书签页，把橙色按钮拖到浏览器书签栏。只拖这一次，以后都能用。

②
打开要抓的文档页

正常打开，登录你自己的账号，等正文显示出来。要整篇就滚动到底。

③
点一下书签

文件立刻下载：文字型存 .txt，图片型（扫描件/PPT）存 .zip 逐页图。

打开书签页 →

这条路不需要填 Cookie、不需要开终端、不需要装任何东西。

2网页端：填个链接就行

①
打开工作台，进「文库提取」

把文档链接粘进「文档地址」，结果类型保持默认的「自动」。

②
点「抓取并解析」

它会自己判断：有原件就下原件，没有就提正文，PPT 只取文字不抓图。

打开工作台 →
提示「403 / 需要登录态」怎么办？（大多数人卡在这）

不要去找 Cookie。403 只是拦住"程序匿名访问"，你浏览器里是有登录态的。

正确做法：用上面第 1 条的书签 —— 它在你的浏览器页面里执行，用的是你自己的登录态，不存在 403。程序已经自动试过桌面/移动/微信三种 UA 和两个 Referer 都被拒，说明这条路只能靠浏览器。

实在要填 Cookie：F12 → Network → 点任意一个请求 → Request Headers 里的 Cookie: 整行复制 → 粘到「Cookie」框。只在填了值时才会发送，且只发给本机代理。

提示「没取到正文 / 页面是 SPA 壳」怎么办？

这个站的正文是 JS 渲染的，HTML 源码里没有。工作台会自动尝试下载原件；原件也没有时，用书签（第 1 条）在页面上直接取渲染后的内容。

3换站：这份文档在别处可能免费

在线版是纯静态站点，跑不了命令行。跨站找免费副本这项能力只在桌面版提供 —— 下载桌面包后运行 tools\wenku_crawler.py。在线版请优先用第 1 条的书签。

# 在线版没有本地环境，跨站找副本请在桌面版执行

在线版可用的只有：书签（第 1 条）与粘贴正文。其余需要本地环境。

?常见问题速查

你看到的该怎么办
403 / 需要登录态用书签（第 1 条）。不要折腾 Cookie。
没取到正文 / SPA 壳改用书签在页面取字；或切「结果类型」到「只取原件」。
只有图片、没有文字扫描件本身没有文字层。用书签，它会导出逐页图 zip。
抓到的字很少换站（第 3 条）；或先滚动到底再点书签。
PDF 里中文变方块换台有中文字体的机器，或把系统字体补齐。
浏览器提示证书不安全跑一次 tools\trust_setup.ps1，然后完全退出浏览器重开。

所有路径都只在本机处理，文件不上传。需要联网的只有：目标站本身、以及可选的 pdf.js / lamejs 编码器。
